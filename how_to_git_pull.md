## how to git pull
first define `origin` and repo (if already exist then use 'set-url' instead)
```
git remote add origin git@github.com:haohao-brian/xv6-riscv
```
source:https://www.freecodecamp.org/chinese/news/error-src-refspec-master-does-not-match-any-how-to-fix-in-git/
```
git add .
git commit -m "new changes"
git push origin hello
```
